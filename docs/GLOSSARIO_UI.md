# Glossário de interface (PT-BR simples)

Termos que aparecem na tela do BOSYN. O público principal são adultos e idosos com perda
auditiva. Nada de jargão técnico, inglês ou linguagem de "terminal". Código: os estilos de texto
ficam em `lib/ui/theme/bosyn_text.dart` (fonte mínima 14).

| Evitar | Usar |
|---|---|
| Trial | Tentativa / "Palavra 3 de 25" |
| XP | Pontos de treino |
| Streak | Dias seguidos |
| STATUS: INITIAL / MODERATE / ADVANCED | (não mostrar; o nível vem do desempenho, ver Etapa 10) |
| Acuidade / IAB | (não usar: o app não mede acuidade clínica) |
| BOOST | (não mostrar; é um ajuste interno de dificuldade) |
| SNR / dB | "Nível de ruído" (fácil → difícil) |
| Hughson-Westlake, protocolo, reversões | "O volume vai subir e descer até achar o mais baixo que você ouve" |
| dB HL | Na tela: "volume". Nos dados: "nível relativo" (triagem, sem calibração) |
| Minimal Pairs | Palavras parecidas |
| Reabilitação neural, neuroplasticidade, remapear | Treino auditivo |
| Check de hardware | Teste do fone |
| Energia Neural / fadiga neural | Pausa sugerida (por tempo de treino) |
| Missão concluída / relatório clínico | Resumo do treino |
| Operador, terminal, identificador | Você, entrar, e-mail |
| PRO / Elite | Plano completo |

**Regras:**
- Frase curta, voz ativa e verbo de ação no botão ("Ouvir de novo", "Continuar").
- Nunca prometer resultado clínico ("recupera", "restaura", "cura").
